# Frontend

Frontend propuesto para la practica, desarrollado con React y Vite.

## Responsabilidad

- Mostrar formularios para seleccionar o ingresar ciudades.
- Consultar la ruta mas corta.
- Consultar todas las rutas posibles.
- Mostrar rutas y distancias.
- Permitir agregar ciudades y conexiones.

## Instalacion

Desde la carpeta `Practica1/frontend`:

```bash
npm install
```

## Ejecucion

Desde la carpeta `Practica1/frontend`:

```bash
npm run dev
```

La aplicacion se conectara al backend en:

```text
http://127.0.0.1:8000
```

## Restriccion principal

El frontend no debe calcular rutas. Solo debe comunicarse con el backend y mostrar la informacion recibida.
